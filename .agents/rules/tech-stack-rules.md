# StudyLounge Tech Stack Rules

Backend:
- TypeScript kullanılmalı.
- NestJS tercih edilmeli.
- PostgreSQL kullanılmalı.
- REST API standart işlemler için kullanılmalı.
- WebSocket gerçek zamanlı sensör, oda ve chat verileri için kullanılmalı.
- Kimlik doğrulamada JWT kullanılmalı.

Mobile:
- React Native Expo kullanılmalı.
- Sensör işlemleri için expo-sensors tercih edilmeli.
- Uygulama hem iOS hem Android desteklemeli.

Web:
- React.js kullanılmalı.
- Tailwind CSS tercih edilmeli.
- State management için Zustand kullanılabilir.

DevOps:
- Git ve GitHub kullanılmalı.
- Docker ve Docker Compose desteklenmeli.
